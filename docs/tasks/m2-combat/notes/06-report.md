## Design as built
- Death flow (B8): `HandleOutOfHealth`/`HandleDeath` synchronous inside the killing execution: step 1 `GE_Dead`; step 2 `CancelAbilities`, `ClearAbilityInput`, `RemoveAllGameplayCues`, `Inventory->StopBeam()`; step 3 `UnregisterHitbox` (B17); then `StartDeath`, replicated `bIsCorpse`, death cue, `AVeloxGameMode::PlayerDied` (scores, broadcasts `AVeloxGameState::OnKill` with `FVeloxKillEvent`), corpse timer. **Next tick** (`CompleteDeath`): floor drop if airborne, `ApplyCorpseState` (collision off, `DisableMovement`) = step 4, then `UnPossess` (step 5), `SetViewTarget(corpse)`, `NotifyControllerDied`. Departure from B8 "UnPossess last, synchronously": a dead pawn stays possessed ≤ 1 tick (input/abilities blocked by the dead tag) so a lethal self-splash inside `PerformMovement` is safe. **Architect to rule.**
- Corpse: capsule+mesh collision off (transparent to Weapon channel), removed after `CorpseLifetime`, `OnDeathFinished` first. Clients: `OnRep_IsCorpse`/`OnRep_PlayerState(null)` detach health component, clear ASC avatar only if still that pawn.
- Death camera: `AVeloxCharacter::CalcCamera`, `DeathCamDistanceCm` in front of the corpse, `DeathCamPitchDegrees` down, camera-channel trace backs off walls (`DeathCamWallOffsetCm`). Does not turn toward the killer (Q3 does).
- Respawn: humans bind `RespawnInputActions` (`IA_Fire`, `IA_Jump` in DefaultGame.ini) → reliable `ServerRequestRespawn` throttled by `RespawnRequestIntervalSeconds`; `AVeloxGameMode::TryRespawn` after `MinRespawnDelay`, forced at `ForceRespawnDelay`. AI controllers auto-respawn after `MinRespawnDelay` (`bAutoRespawnAIControllers`, default on; task 08 sets false if lane dummies should stay dead).
- Spawn selection: `ShouldSpawnAtStartSpot` false, `ChoosePlayerStart` overridden; world-free `GameModes/VeloxSpawnSelection.h`: occupied starts excluded, starts within `SpawnAvoidRadiusCm` of a living enemy skipped while a farther one exists (addition to the ADR rule), uniform pick among the farthest half by nearest-enemy distance; telefrag only if every start is occupied (`Velox.Damage.Telefrag`, protection removed first). Telefrag path not exercised live (unit test only).
- Spawn protection: `PlayerState::ApplySpawnProtection` after `GE_SpawnInit` every possession (default 0 s = off, ADR open question 2), ends on first `UVeloxGameplayAbility_Fire` when `bSpawnProtectionEndsOnFire`.
- Pits: `FellOutOfWorld` applies `EnvironmentKillDamage` on the pawn's own ASC (no knockback); falling corpses left to the timer.
- Readability: `PlaceholderBody` cylinder scaled to the capsule, hidden from the owner's camera, unlit `Content/Materials/M_PlayerBody.uasset` (vector param "Color", bootstrap-created). Game mode assigns the first unused of an 8-colour `PlayerColorPalette` (in `UVeloxCombatSettings`); palette index replicated via PlayerState (not the colour). Corpses dimmed by `CorpseColorScale`.
- HUD: hit marker from state in `AVeloxPlayerController` (last hit time, damage, kill flag; white X, red/larger on kill); "YOU WERE FRAGGED" overlay with countdown then "Press FIRE". (Feedback component lacks the kill flag and was out of scope.)
- New settings: `TelefragDamage`, `EnvironmentKillDamage`, `RespawnRequestIntervalSeconds`, `DeathCamDistanceCm`, `DeathCamPitchDegrees`, `DeathCamWallOffsetCm`, `CorpseDropMaxCm`, `CorpseColorScale`, `PlayerColorPalette`, `HitMarkerSeconds`, `HitMarkerSize`.
