## Goal
Task 03 made Easy/Medium spray but the held trigger also fired the *single* shots of RG/SG/RL under the gate-free release cone (Medium's railgun fell from 49 % to 7.6 %; the RG skill order is Easy 86 > Expert 61 > Hard 46 > Medium 8). D51 (2)(a) confines the three D50 spray fields to automatic weapons; single-shot weapons run D14's rule unscaled at every preset. In the same pass the runner takes the bands D51 derived from the acceptance rounds (set sums Σ kills ≥ 20, Σ frags ≥ 20, Σ camp episodes ≥ 7, FFA Σ kills ≥ 74; Mega "≥ 1 return ≤ 3 s and ≥ 2 returns ≤ 10 s"), the per-weapon near-human table (report-only), the slow-throughout round labelling, and the FFA soak scripts move from the evidence directories into `infra/ci/`. One set per judged script then confirms everything passes. No knob is tuned in this task; an `OUT` is reported as a number.
