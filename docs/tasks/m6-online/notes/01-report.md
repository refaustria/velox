## Findings
1. **`Velox.sh` does not `exec`.** It runs the binary as a child; SIGTERM to the wrapper PID orphans the engine. The smoke therefore starts `Velox/Binaries/Linux/Velox Velox <args>` directly. The M6 systemd unit (task 06) must do the same (or use `KillMode=control-group`).
2. **Development server crashes ~61 s after start with a fatal GC verification error** (`GarbageCollectionVerification.cpp:156`, "Encountered 41 object(s) breaking Disregard for GC assumptions"): `VeloxAudioSettings` (CDO, property `LoadedAssets`) references SoundWave/SoundAttenuation/SoundConcurrency/SoundMix assets that are not in the root set. Reproduced twice with the packaged Development server (first periodic GC, `gc.TimeBetweenPurgingPendingKillObjects` 61.1 s). This is a Source/Audio bug (out of scope here) and a blocker for any server that must run longer than a minute; in Shipping the verification is compiled out but the same dangling reference pattern can free the assets. The 30 s smoke window passes only because it ends before the first GC. Needs a fix (hold the references in a GC-visible owner, e.g. a GameInstance subsystem UPROPERTY) before task 02/06.
3. **Shipping client does not join headless.** `Velox-Linux-Shipping 127.0.0.1:7797 -game -nullrhi` stays alive (running, ~230 MB RSS) but never opens a connection within 50 s; Shipping has no log output (it printed only `5.8.4-... 1018 0`, `Disabling core dumps.` and, on SIGTERM, `FUnixPlatformMisc::RequestExit ... Exiting abnormally (error code: 143)`). The join handshake is therefore verified with the Development client from the server archive (same code, same net version `Checksum: 4065349793`, "Welcomed by server"). Not diagnosed further; likely needs a GPU/RHI path or logging in Shipping. Candidate for the release smoke (task 13).
4. `~/.local/bin/env` on this host is a non-executable shell snippet that shadows `/usr/bin/env`; UAT staging fails with "Permission denied" until it is removed from PATH. Handled in the script (host file untouched).
5. `Config/DefaultGame.ini` `MapsToCook` lacks `/Game/Maps/DM1/L_DM1` (only `L_DM1_Blockout`); the art map is not in the package. Not changed (decision 40 territory), lead to confirm for the first release.
6. The listen line used by the smoke: `LogNet: Name:GameNetDriver Def:GameNetDriver IpNetDriver_... IpNetDriver listening on port 7797`. The net version line: `LogNetVersion: Velox 0.6.0, NetCL: 55116800, EngineNetworkVersion: 44, GameNetworkVersion: 0 (Checksum: 4065349793)` (only logged when a client connects; `-LogCmds="LogNetVersion Log"`). `MANIFEST.json` `net_version` stores the checksum.
