# 04g — Segment line-of-walk check: repath when the straight steer to the segment target is blocked

**Milestone:** M4 Bots
**Agent:** dev-hard
**Status:** todo
**Depends on:** 04e and 04f merged on `m4-bots` (head 773ad0e or later); ADR 0005 D35 (the rule), D36 (the bands), D37 (d) (the single link budget). Runs in parallel with 07 (disjoint files, see ADR D38); the FFA soak must not overlap with 07's nettest rounds on the machine.

## Goal
A bot that the combat overlay has pushed off its path corridor no longer steers straight at a segment end point through world geometry. The follower checks the straight line to the current segment target on the nav mesh every 0.25 s and, when it is blocked well short of the target, lands and asks the controller for a repath (no strike, no `StopMove`). The five "hop in place at (±87.5, ±87.5)" strikes of the post04f soak (the cross's inner corners, ADR 0005 D35 evidence) and the 6 s slab-face dwell of run 9 become sub-second detours. Secondary: one timeout budget per link segment (D37 (d)). Verified by a functional test with a staged stale path and by ten FFA runs against the D36 bands.
