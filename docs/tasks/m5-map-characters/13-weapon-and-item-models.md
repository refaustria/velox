# 13 — Weapon and item models: Blender script, import, cosmetics and pickup meshes

**Milestone:** M5 Map + characters
**Agent:** dev
**Status:** todo
**Depends on:** 09 (`UVeloxWeaponCosmetics`), 10 (`UVeloxItemDefinition::Mesh`), 11 (`import_art.py`, `export_common.py`); ADR 0006 §4.6, §3 items

## Goal
Six readable low-poly weapon meshes (world = view mesh, `muzzle` socket) and the item meshes (health 5/25/50/Mega, shard, YA, RA, ammo box × 6 variants by colour, Quad) generated by `Tools/blender/weapons_items.py`, imported headless, assigned to `DA_WeaponCosmetics_*` and `DA_Item_*`; pickups render their mesh instead of the placeholder. View offsets tuned by the rule in ADR 0006 §4.6 (visible lower-right, muzzle at ~45 cm forward).

## Scope — files/modules the agent may touch
- `Tools/blender/weapons_items.py` (new), `Tools/editor/import_art.py` (`--static <dir>`), `Tools/editor/create_cosmetics_content.py` (mesh + offsets), `Tools/editor/create_item_content.py` (mesh field), `Items/VeloxPickup.cpp` (use `Mesh` when set; keep the placeholder path), `ArtSource/Weapons/weapons.blend`, `ArtSource/Export/SM_*.fbx`, `Content/Weapons/Meshes/**`, `Content/Items/Meshes/**` (LFS), `docs/art/weapons-spec.md`

## Relevant ADRs / references
- ADR 0006 §4.6 (view model, offsets, scale 0.6 via first-person path), §8 (weapons ≤ 1.5 k tris, one material), §4.3/style guide (items saturated and distinct; health = white/green cross family, armor = yellow/red, Mega = blue, Quad = cyan glow, ammo = weapon colour)
- ADR 0004 §1 (item list), `Tools/editor/README.md` Python notes

## Acceptance criteria
- [ ] `weapons_items.py`: six weapons ≤ 1 500 tris each, distinct silhouettes (MG: short barrel + drum; SG: double barrel; PG: coil + sphere; RL: tube + box; LG: prongs; RG: long rail + fins), grip origin at (0,0,0), barrel along +X, an empty named `muzzle` at the barrel tip (exported as a socket: name prefix `SOCKET_` per UE FBX convention); items: 11 meshes ≤ 400 tris, origin at the base, height ≤ 60 cm, UV0 for a flat-colour palette texture `T_Items_Palette` (16 × 1 px).
- [ ] `import_art.py --static ArtSource/Export --verify`: static meshes with simple collision removed (`NoCollision`; pickups use their own trigger), lightmap UVs off (dynamic objects), one material slot, `muzzle` socket present on every weapon mesh; `M_Items_Palette`/`M_Weapon_Flat` unlit-ish lit materials with vertex-colour or palette UVs.
- [ ] `DA_WeaponCosmetics_*`: `WorldMesh = ViewMesh = SM_Weapon_<Name>`, `ViewOffset` per weapon from a table in the script (start: location (30, 15, −15) cm, rotation (0, 0, 0); RL/RG +10 cm forward), `ViewScale 1.0` (the first-person scale 0.6 handles size); `DA_Item_*::Mesh` set; `AVeloxPickup` shows the mesh (rotation off per the existing M5 note; glow via the existing placeholder material parameter kept for the Quad).
- [ ] Headless `L_ItemTest -game -nullrhi`: every pickup logs its mesh assigned; `L_CombatTest` `FireRun` still PASS.
- [ ] `docs/art/weapons-spec.md`: silhouettes, dimensions, socket, colours; what the human replaces later.
- [ ] Without Blender: script + spec; import path proven with a fixture (`/Engine/BasicShapes/Cylinder` exported and re-imported with a `SOCKET_muzzle` added via Python after import).
