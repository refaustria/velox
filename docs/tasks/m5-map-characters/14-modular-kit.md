# 14 — Modular environment kit: Blender script, import with lightmap UVs, materials

**Milestone:** M5 Map + characters
**Agent:** dev
**Status:** todo
**Depends on:** 11 (`export_common.py`, `import_art.py`), human question 4 (theme) — proceed with a neutral "concrete and steel" default if unanswered; ADR 0006 §2, §5, §8

## Goal
≤ 25 kit pieces on the 400 cm module that can replace every box the DM1 layout uses: floor tile, wall 400 × 400 (plain, with trim, with door frame 300 and 400), half wall, pillar, ceiling tile, 15° ramp (400 long), stairs (20 cm risers, 400 run), ledge edge/railing stub, bridge segment, jump-pad base ring, item pedestal, light fixture (emissive), skirting/trim. Each piece has UV0 for materials, UV1 lightmap (generated at import), ≤ 600 tris, and one of ≤ 8 material instances of `M_Kit_Master`. Palette follows the style guide (V ≤ 0.5, S ≤ 0.25).

## Scope — files/modules the agent may touch
- `Tools/blender/kit.py` (new), `Tools/editor/import_art.py` (`--kit <dir>`: lightmap UV generation, resolution per piece, collision `NoCollision`), `Tools/editor/create_cosmetics_content.py` or a new `create_kit_materials.py`, `ArtSource/Kit/kit.blend`, `ArtSource/Export/SM_Kit_*.fbx`, `ArtSource/Textures/T_Kit_*.png` (≤ 1024², ≤ 6 textures), `Content/Environment/Kit/**`, `Content/Environment/Lighting/TC_Sky_DM1` (LFS), `docs/art/kit-spec.md`

## Relevant ADRs / references
- ADR 0006 §2 (kit replaces boxes; clip-first; protrusion rule ≤ 5 cm into walkable space), §5 (lightmap resolutions 128/64/32, `bGenerateLightmapUVs`, `MinLightmapResolution 64`, `DstLightmapIndex 1`), §8 (budgets: ≤ 25 meshes × ≤ 8 materials), style guide (task 11)

## Acceptance criteria
- [ ] `kit.py` emits every piece listed above with exact module dimensions (floor 400 × 400 × 20 top at Z 0; wall 400 × 20 × 400; ramp rises 107 cm over 400 — 15°; stairs 5 × 20 cm risers over 400 run, matching the layout's `stairs` record), pivots at the piece's floor-level corner the generator expects (documented in `kit-spec.md`), hard edges only, no n-gons, ≤ 600 tris; textures generated procedurally in Blender (noise + grid) and baked to PNG ≤ 1024².
- [ ] `import_art.py --kit`: `bGenerateLightmapUVs`, `DstLightmapIndex 1`, `MinLightmapResolution 64`, per-piece `LightMapResolution` (floor 128, wall 64, trims/pillar 32, bridge 64) set on the static mesh, `NoCollision`, `--verify` asserts UV channel count = 2, tri budget, one material slot, 25-piece cap.
- [ ] Materials: `M_Kit_Master` (base colour tint × texture, roughness constant, optional emissive for the fixture), ≤ 8 `MI_Kit_*`; the palette assertion from the style guide runs in the script (no instance with V > 0.5 or S > 0.25 except the emissive fixture).
- [ ] `TC_Sky_DM1`: a 128 px cubemap generated by script (gradient sky, neutral grey ground) imported as `TextureCube`.
- [ ] `docs/art/kit-spec.md`: piece table (name, size, pivot, lightmap res, material), texel density, what the human may replace.
- [ ] Without Blender: script + spec; import path proven with `/Engine/BasicShapes/Cube` exported to FBX and imported through `--kit` (lightmap UVs generated, verify passes).
