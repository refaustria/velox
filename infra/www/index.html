Velox

A fast arena FPS in the spirit of Quake 3 Arena, built on Unreal Engine 5.8.

Strafe-jumping, rocket jumps and six classic weapons, with server-authoritative netcode and bots that move like players. Velox is in open playtest: expect rough edges.

Downloads

Download the latest build from the downloads page.

Servers

The live server list needs JavaScript. Without it, open servers.json, or use the direct-IP field in the game's main menu.

How to play

Linux (tested headless only)

This build has been tested headless only, not yet on a desktop with a GPU. Extract the archive (tar --zstd -xf Velox-*-Linux.tar.zst), then run ./Velox.sh. You need a Vulkan driver and glibc 2.28 or newer.

macOS

The build is ad-hoc signed, not notarized. After unzipping, right-click → Open on Velox.app, or remove the quarantine flag: xattr -dr com.apple.quarantine Velox.app.

Windows

Not yet available. A Windows build is deferred to milestone M7.

Connecting

Pick a server in the in-game Servers menu, or paste an address from the list above into the direct-IP field.

Privacy

The server logs connection IP addresses for 14 days to diagnose problems; the status page shows player counts only. This site sets no cookies and loads nothing from other hosts.
